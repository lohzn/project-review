# Project Review Submission
 
This repository contains 4 React + TypeScript projects built with Vite and styled with Tailwind CSS
 
## Projects
 
1. **AirBnb Experiences clone** (folder: `/airbnb-exp/`)
 
2. **Meme Generator** (folder: `/meme-generator/`)
 
3. **Notes Application** (folder: `/notes-app/`)
 
4. **Tenzies** (folder: `/tenzies/`)
 
## How to run a project
 
1. Navigate into the project folder: `cd tenzies/` (or any other project listed above)
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open the localhost URL shown in the terminal.
 
## Tech Stack
 
- React 19.2.8
- TypeScript 6.0.2
- Vite 8.2
- TailwindCSS 4.3.3
